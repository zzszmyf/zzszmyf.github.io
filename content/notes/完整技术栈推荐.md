# 完整技术栈推荐

> 域名、部署、数据库、工具的选择指南

---

## 技术栈决策树

```
你的主要用户在哪里？
    │
    ├── 国内为主 ────────────────────────────┐
    │                                        │
    ├── 需要后端吗？（登录、支付、数据库）      │
    │       │                                │
    │       ├── 不需要 ──→ 方案A：国内静态方案  │
    │       │              阿里云域名 + OSS    │
    │       │                                │
    │       └── 需要 ────→ 方案B：国内全栈方案  │
    │                      阿里云/腾讯云       │
    │                                        │
    └── 国内+海外混合 ────────────────────────┘
            │
            ├── 不需要后端 ──→ 方案C：Cloudflare 全栈
            │                     域名+Pages+CDN
            │
            └── 需要后端 ─────→ 方案D：混合部署
                                 前端 Cloudflare/Vercel
                                 后端 阿里云/腾讯云
```

---

## 方案对比

### 方案 A：国内静态方案（国内企业客户）

**适用场景**：
- TOB 国内企业客户为主
- 纯展示型博客
- 追求国内访问速度

**技术栈**：
| 层级 | 选择 | 价格 |
|------|------|------|
| 域名 | 阿里云/腾讯云 `.com` + `.cn` | ¥100/年 |
| DNS | 阿里云 DNS/腾讯云 DNSPod | 免费 |
| 部署 | 阿里云 OSS / 腾讯云 COS | ¥10-30/月 |
| CDN | 阿里云 CDN / 腾讯云 CDN | ¥20-50/月 |
| SSL | 阿里云/腾讯云免费证书 | 免费 |
| **总计** | | **¥400-800/年** |

**优点**：
- ✅ 国内访问极快
- ✅ 客户信任度高（阿里云/腾讯云品牌）
- ✅ 备案方便

**缺点**：
- ❌ 成本高于海外方案
- ❌ 配置稍复杂

**推荐**：国内企业客户为主的顾问

---

### 方案 B：国内全栈方案（需要后端）

**适用场景**：
- 需要用户系统、CMS、CRM
- 做 SaaS 产品
- 高并发、稳定性要求高

**技术栈**：
| 层级 | 选择 | 价格 |
|------|------|------|
| 域名 | 阿里云/腾讯云 | ¥100/年 |
| 服务器 | 阿里云 ECS / 腾讯云 CVM | ¥100-500/月 |
| 数据库 | 阿里云 RDS / 腾讯云 CDB | ¥100-300/月 |
| 对象存储 | 阿里云 OSS / 腾讯云 COS | ¥10-50/月 |
| CDN | 阿里云 CDN / 腾讯云 CDN | ¥50-200/月 |
| **总计** | | **¥4000-12000/年** |

**优点**：
- ✅ 完全可控
- ✅ 国内合规（已备案）
- ✅ 技术支持好

**缺点**：
- ❌ 成本高
- ❌ 需要运维能力

**推荐**：业务稳定、月入 5 万+ 后考虑

---

### 方案 C：Cloudflare 全栈（推荐起步）

**适用场景**：
- 个人品牌博客
- 轻量 API 需求
- 追求性价比

**技术栈**：
| 层级 | 选择 | 价格 |
|------|------|------|
| 域名 | Cloudflare Registrar | $10/年 (~¥70) |
| DNS | Cloudflare DNS | 免费 |
| 部署 | Cloudflare Pages | 免费 |
| 边缘函数 | Cloudflare Workers | 免费 10万次/天 |
| 数据库 | Cloudflare D1 | 免费 5GB |
| 存储 | Cloudflare R2 | 免费 10GB |
| CDN | Cloudflare CDN | 免费 |
| **总计** | | **¥70/年** |

**优点**：
- ✅ **成本极低**
- ✅ 全球访问快（包括国内）
- ✅ 一个平台管理所有
- ✅ 自动 HTTPS、自动部署

**缺点**：
- ⚠️ 未备案域名国内访问偶慢（可接受）
- ⚠️ Workers 有冷启动

**推荐**：**首选方案**，doraeMeng 推荐配置

---

### 方案 D：混合部署（进阶）

**适用场景**：
- 国内外用户都有
- 需要复杂后端但想省钱
- 已有部分基础设施

**技术栈**：
| 层级 | 选择 | 价格 |
|------|------|------|
| 域名 | Cloudflare/Namecheap | $10/年 |
| DNS | Cloudflare（按地区分流） | 免费 |
| 前端 | Cloudflare Pages / Vercel | 免费 |
| 后端 | 阿里云函数计算 / 腾讯云 SCF | ¥0-100/月 |
| 数据库 | PlanetScale / Supabase | $0-25/月 |
| **总计** | | **¥500-2000/年** |

**优点**：
- ✅ 平衡成本与性能
- ✅ 国内用户走国内线路
- ✅ 海外用户走 Cloudflare

**缺点**：
- ⚠️ 架构复杂
- ⚠️ 需要配置 DNS 分流

**推荐**：有技术能力，业务增长期

## 避坑指南

### ❌ 不要这样做

1. **自建服务器**（初期）
   - 维护成本高、安全风险大
   - 除非你有专职运维

2. **用 Heroku**（国内）
   - 访问慢、贵、已衰落

3. **买太多域名后缀**
   - `.com` + `.cn` 足够，其他浪费钱

4. **忽视备份**
   - 代码放 GitHub，数据定期导出

### ✅ 应该这样做

1. **先用免费额度**
   - Cloudflare/Vercel 免费版够用很久

2. **监控成本**
   - 设置预算告警，避免意外账单

3. **保持简单**
   - 能静态就别动态，能 Serverless 就别服务器

4. **预留迁移路径**
   - 代码解耦，方便换平台
