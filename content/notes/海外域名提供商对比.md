GoDaddy 的首页常把首年价格打到 $0.99，续费价目表里写的是 $18-22，Whois 隐私再加 $10/年。把这三个数字放在一起，海外域名比价的第一条结论就出来了：首年价格是最不重要的一列。域名是两三年起持有、到期还要续的东西，真正要算的是续费价、隐私费和转出成本。

## Cloudflare Registrar：按成本价卖

Cloudflare 的 .com 注册和续费都是 $9.77/年，按批发价加 ICANN 费用卖，不靠首年低价和续费溢价赚钱。它的隐私保护免费，DNS 也免费，解析走 Cloudflare 的 anycast 网络。限制有两个：域名必须使用 Cloudflare DNS，不能保留 Registrar 同时换别家解析；新注册名额是分批开放的，你查的时候能不能买并不确定，很多情况下只能把已有域名转进去。支付支持信用卡和 PayPal，没有中文客服。

如果这两条限制都能接受，Cloudflare 是长期持有 .com 最省心的选择。三年域名费是 $29.31，比 Namecheap 的约 $38 便宜不到 $9；它真正的价值在于价格透明，不用担心第二年突然涨到 $20 以上。把域名当基础设施的人，会更看重这个确定性，省几美元排在后面。

## Namecheap：稳定默认

Namecheap 首年 $10.28，续费约 $14，WhoisGuard 隐私免费，DNS 和邮箱转发也免费。它经常有新用户 $5.98 的首年码，黑五和网一有折扣；这些促销适合第一年，但续费价才是长期成本。支付支持信用卡、PayPal 和 Bitcoin，客服响应快，界面也比老牌注册商清楚。

Namecheap 的优势是没有明显短板：价格不是最低，但续费可控；隐私免费；转入转出流程成熟；中文用户用 PayPal 也能付。它适合不想在域名上花时间、也不想被续费刺客咬一口的人。我的默认选择是它，Cloudflare 有注册名额时才会换过去。

## Porkbun：极简，不推销

Porkbun 的 .com 是 $10.37/年，续费同价，隐私保护和 SSL 都免费，结账时不会塞一堆附加服务。界面极简，适合讨厌 upsell 的人。支付支持信用卡、PayPal，部分区域支持支付宝。它的短板是知名度低、客服渠道少、没有中文，遇到域名被锁或转移争议时，沟通成本会比 Namecheap 高。

## 其他家：只在特定条件下有意义

Name.com 的 .com 是 $12.99/年，支持支付宝；需要支付宝付款、又不想用国内注册商的人可以选它，三年总成本约 $54（含隐私费）。Hover 是 $15.99/年，隐私免费，送邮箱转发，界面极简，适合不差钱、追求干净体验的人。Gandi 是 $15.50/年，隐私免费，送 2 个邮箱，老牌欧洲注册商，适合欧洲业务或对隐私要求高的用户；它的价格比 Cloudflare 贵近六成，界面也偏复古。Google Domains 已经关闭并迁到 Squarespace，新用户没有必要再考虑，Squarespace 的主营业务是建站，域名只是附带。

GoDaddy 是另一个极端：首年 $0.99-12，续费 $18-22，支付支持信用卡、支付宝和微信，客服支持中文和 24/7。常见的玩法是首年买入、之后转出到 Cloudflare 或 Namecheap。这个玩法能省钱，但多了一次转移操作和一段不能转出的锁定期；如果忘记续费或转移失败，省下的十几美元会变成赎回费。新手可以用它买第一个域名，熟悉流程后转走，不建议长期停留。

## 三年账与隐私

按三年持有算，Cloudflare 是 $29.31，Porkbun 是 $31.11，Namecheap 约 $38.28，Name.com 约 $53.94，GoDaddy 按上面的首年价和续费价算，三年加隐私在 $67-86 之间。这些数字里，Cloudflare 和 Namecheap 的差距不到 $9，GoDaddy 和它们的差距是几十美元。为了几美元首年差价选择一个续费贵、转移麻烦的注册商，账算不过来。

隐私保护是另一笔账。2018 年 GDPR 之后，很多注册局会对自然人的 Whois 数据做脱敏，但这不意味着所有注册商都提供隐私服务：GoDaddy 要收 $10/年，Name.com 要收 $4.99/年，Cloudflare、Namecheap、Porkbun、Hover、Gandi 免费。在没有隐私保护或注册局未脱敏的情况下，姓名、电话、邮箱会进 Whois 数据库，接着是推销电话和诈骗邮件。对个人博客，隐私保护应该当成默认项，不要等接到第一个骚扰电话才去开。

## 转出与续费

域名转出有硬规则：新注册或刚转入的域名 60 天内不能转出，转出前要在原注册商解锁、拿 Auth Code，转入方发起后等 5-7 天。转移成功通常会顺延一年有效期，转移费按续费价收，所以最佳时机是域名还有几个月到期、又不急着换 DNS 的时候。

自动续费要开，账号要开双因素认证，Auth Code 和注册商账号的恢复邮箱要单独保存。域名过期后，先是宽限期，随后进入赎回期，赎回费通常远高于正常续费；如果账号丢了，连赎回都做不了。一个 $10 的续费失误，可能变成几百美元的赎回费，或者直接丢掉一个已经用了两年的品牌名。

## 我的选择

默认用 Namecheap，隐私免费、续费可控、转入转出成熟；Cloudflare 有注册名额、且我愿意把 DNS 放在 Cloudflare 时，换到它的 $9.77 成本价；需要极简和支付宝时看 Porkbun 或 Name.com；GoDaddy 只在首年促销且确定会转出时用。国内企业客户为主时，域名放在阿里云，¥70/年，隐私 ¥30/年，备案和解析都在一个后台，省下的沟通成本比海外注册商的差价更值钱。

价格会随促销和汇率变化，下单前以注册商页面为准。三年后的总账通常只差几十美元，真正让人后悔的是续费忘记、账号丢失或转移卡住。选一个流程透明、隐私免费、能顺利转出的注册商，然后把自动续费和 2FA 打开，比继续比价更有用。
