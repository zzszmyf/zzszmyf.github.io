快速开始指南 #

5 分钟找到你的起点

我现在处于哪个阶段？ #

阶段一：完全空白（还没开始） #

特征：

  • 有技术背景，但没做过商业咨询
  • 不知道从哪里开始
  • 没有博客，没有案例展示

立即行动（今天）：

  1. 阅读 03-AI落地专家内容营销策略 - 明确你的定位
  2. 写下你的定位宣言：

    “我帮助 [XX行业] 企业通过 AI 实现 [具体效果]，提供 [服务类型] 服务。”

  3. 列出 3 个你可以展示的项目案例

本周完成：

  • 购买域名 doraemg.com + doraemg.cn
  • 搭建博客（参考 15-Cloudflare部署方案详解）
  • 发布第一篇案例文章

参考文档：

  • 03-AI落地专家内容营销策略
  • 07-垂直行业选择指南
  • 10-90天启动计划
  • 15-Cloudflare部署方案详解

阶段二：博客已搭建（有基础） #

特征：

  • 博客已经上线
  • 有 1-3 篇文章
  • 但流量很少，没有咨询

立即行动（今天）：

  1. 阅读 08-内容营销执行手册 - 优化内容策略
  2. 检查 SEO 基础（标题、描述、关键词）
  3. 制定内容日历：每周 1 篇长文 + 3-5 条短动态

本周完成：

  • 优化已有文章的 SEO
  • 在知乎、即刻、LinkedIn 开设账号并同步内容
  • 主动联系 3 个潜在引荐人

参考文档：

  • 08-内容营销执行手册
  • 12-域名SEO与GEO实战指南

阶段三：有线索在谈（商务阶段） #

特征：

  • 有潜在客户咨询
  • 不知道怎么报价、怎么谈
  • 担心踩坑

立即行动（今天）：

  1. 阅读 04-TOB咨询商务准备清单 - 准备商务材料
  2. 准备标准合同模板
  3. 确定你的报价区间

本周完成：

  • 完成 1 份服务说明书
  • 准备提案模板
  • 完成首次 Discovery Call

参考文档：

  • 04-TOB咨询商务准备清单
  • 05-客户沟通与提案技巧
  • 09-常见陷阱与避坑指南

阶段四：已有客户（项目交付） #

特征：

  • 正在执行项目
  • 需要管理客户关系
  • 希望获得更多转介绍

立即行动（今天）：

  1. 阅读 09-常见陷阱与避坑指南 - 避免项目踩坑
  2. 建立项目沟通节奏（周报、里程碑汇报）
  3. 准备案例素材（截图、数据、反馈）

本周完成：

  • 向客户请求推荐语（书面）
  • 整理项目案例，准备发布
  • 请求客户推荐同行

参考文档：

  • 09-常见陷阱与避坑指南
  • 06-顾问形象与心态建设

最常见的 5 个问题 #

Q1: 我没有案例怎么办？ #

A: 用过往项目（脱敏处理），或先做 1-2 个低价/免费项目积累案例。参考 03-AI落地专家内容营销策略 的"选题库"。

Q2: 域名选 .com 还是 .cn？ #

A: 都买。.com 是主域名，.cn 保护品牌。参考 14-海外域名提供商对比。

Q3: 需要注册公司吗？ #

A: 初期可以个人名义，月收入稳定过万后再考虑注册公司。参考 04-TOB咨询商务准备清单。

Q4: 多久能接到第一个客户？ #

A: 通常 1-3 个月。关键：内容输出 + 人脉激活。参考 10-90天启动计划。

Q5: 报价怎么定？ #

A: 时薪 ¥2000-5000 或项目制 ¥5-20万。参考 04-TOB咨询商务准备清单 的报价策略。

30 天极简计划 #

Week 1: 基础建设 #

  • 确定定位和行业
  • 购买域名
  • 搭建博客
  • 发布第一篇案例文章

Week 2: 内容启动 #

  • 发布第二篇文章
  • 开设知乎/即刻账号
  • 同步内容到各平台
  • 联系 3 个潜在引荐人

Week 3: 获客尝试 #

  • 发布第三篇文章
  • 主动回答知乎相关问题
  • 参加 1 次线下活动
  • 准备服务说明书

Week 4: 优化迭代 #

  • 复盘前 3 周效果
  • 优化内容方向
  • 跟进所有线索
  • 制定下月计划

需要我帮你做什么？ #

  • 搭建博客：VitePress + Cloudflare Pages 部署
  • 检查域名可用性：doraemg.com 等
  • 规划内容策略：根据你的背景定制选题
  • 审阅定位宣言：帮你打磨个人简介

💡 记住：完成比完美重要。先启动，再优化。
